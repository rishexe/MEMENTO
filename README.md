# Sikkim Gamified Tourism Platform

This project is a mobile-first tourism platform for Sikkim, designed as a gamified travel experience.

## Tech stack
- Frontend: React + TypeScript
- Backend: FastAPI + Python
- Database: Supabase + PostgreSQL

## Project structure
- frontend/
- backend/
- docs/
- shared/
- scripts/
- tests/

## Notes
This repository is the foundation for the product architecture and implementation work.
